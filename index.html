Введіть персональний токен Monobank. Він зберігається у localStorage цього браузера. Імпортуються операції лише в обраній валюті бюджету за останні 30 днів.

Токен надає доступ до фінансових даних. Не вводьте його на чужому пристрої та не публікуйте. Ця сторінка викликає API напряму; якщо браузер блокує запит через CORS, потрібен власний довірений HTTPS-проксі-сервер. Не використовуйте публічні проксі: вони можуть викрасти токен.
