# Сімейний бюджет Ковальчуків

## Налаштування AI-помічника (Grok / xAI)

У Cloudflare Dashboard відкрийте **Workers & Pages → ваш Worker → Settings → Variables and Secrets → Add**. Створіть secret з назвою `XAI_API_KEY`, вставте API key з акаунта xAI і збережіть. Не додавайте ключ у код, GitHub чи браузер. Після зміни секрету перезапустіть або задеплойте Worker, якщо Cloudflare цього попросить.

Ендпоінт `POST /api/ask` використовує цей секрет для запиту до xAI; без нього повертає зрозуміле повідомлення про налаштування. Фронтенд надсилає питання й лише агреговані підсумки бюджету.

## Розробка та деплой

Встановіть Node.js та виконайте `npm install`. Локально запустіть `npm run dev`, для деплою — `npm run deploy`. Monobank token налаштовується окремим секретом `MONOBANK_TOKEN`.
