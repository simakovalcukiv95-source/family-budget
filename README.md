# Сімейний бюджет Ковальчуків

Статичний адаптивний фронтенд (`index.html`) і Cloudflare Worker (`worker.js`) в одному застосунку. Worker обслуговує сайт і надає `/api/monobank` та `/api/advice`.

## Розробка та деплой

1. Встановіть Node.js, потім у корені проєкту запустіть `npm install`.
2. Увійдіть у Cloudflare: `npx wrangler login`.
3. Для рекомендованого зберігання токена додайте його як Worker secret: `npx wrangler secret put MONOBANK_TOKEN` (або `npm run secret:monobank`). Секрет не потрапляє в репозиторій, HTML чи браузер.
4. Локальний запуск: `npm run dev`.
5. Деплой сайту і Worker разом: `npm run deploy`.

Cloudflare створить URL Worker. Відкрийте цей URL — `/api/*` обробляє Worker, інші маршрути віддаються зі Static Assets. Для наступних змін достатньо повторити `npm run deploy`.

## Monobank API

`POST /api/monobank` приймає JSON `{ "from": 1730000000, "to": 1732678400, "currency": "UAH" }`. У персональному режимі допускається `{ "token": "...", ... }`, але рекомендовано використовувати secret `MONOBANK_TOKEN`, тоді токен не передається зі сторінки. Worker бере всі рахунки з `client-info`, запитує виписки кожного рахунку, нормалізує операції, повертає рахунок/картку-джерело та результати часткових помилок. Ідентифікатори транзакцій зберігає фронтенд для захисту від дублів.

Вікно виписки обмежене останніми 31 днями відповідно до обмежень Monobank API. Запити виписок виконуються послідовно; API може повернути обмеження частоти запитів. Якщо один рахунок не відповідає, Worker повертає операції інших і масив `failures`.

## API

- `POST /api/monobank` — виписки всіх доступних рахунків токена.
- `GET` або `POST /api/advice` — короткі базові рекомендації, готова точка розширення.

Бюджетні операції, цілі та кредити поки зберігаються у `localStorage` пристрою. Експортуйте резервну копію з інтерфейсу для перенесення даних. Токен, введений у налаштуваннях, діє лише до закриття/перезавантаження сторінки; для автоматичного оновлення без введення токена налаштуйте Worker secret.
