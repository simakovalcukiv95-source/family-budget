# Сімейний бюджет Ковальчуків

## AI-помічник (без зовнішнього API-ключа)

AI-помічник використовує Cloudflare Workers AI через binding `AI`, налаштований у `wrangler.toml`. Переконайтеся, що Workers AI доступний у Cloudflare акаунті та Worker задеплоєний із binding. Секрет `XAI_API_KEY` для помічника не потрібен.

## Розробка та деплой

Встановіть Node.js та виконайте `npm install`. Для локальної розробки запустіть `npm run dev`, для деплою — `npm run deploy`. Monobank token налаштовується окремим секретом `MONOBANK_TOKEN`.

Бюджетні операції, цілі й кредити зберігаються у localStorage браузера; регулярно експортуйте резервну копію з налаштувань.
